# MuscuLog v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA mobile en français de suivi de musculation (séries/reps/charges) avec timer de repos automatique et sauvegarde localStorage + GitHub Gist.

**Architecture:** Application une-page vanilla JS sans build : `index.html` (3 écrans : Séance / Historique / Réglages), `app.js` (modules store / sync / timer / ui), `styles.css`, `sw.js` + `manifest.json` pour l'installabilité et le hors-ligne. Données JSON versionnées dans `localStorage` (clé `musculog-data`), poussées vers un Gist privé après chaque modification.

**Tech Stack:** HTML/CSS/JS vanilla, GitHub Gist REST API, GitHub Pages. Tests de la logique pure (store, merge de sync) via `node --test` dans `tests/`.

## Global Constraints

- Interface entièrement en **français**.
- Aucune dépendance externe, aucun build ; les fichiers se servent tels quels.
- Mobile-first (iOS Safari), cibles tactiles ≥ 44 px, utilisable à une main.
- Chaque écriture de données passe par `store.save()` (écriture localStorage immédiate, jamais différée).
- `sw.js` : constante `CACHE = "musculog-vN"` incrémentée à chaque déploiement.
- Design : suivre la direction produite par le skill `ui-ux-pro-max` (Task 1).
